
# Customer Churn & Sales Trend Analysis Using Python

## Project Overview
This project analyzes an E-commerce Online Retail dataset to understand customer purchasing behavior, sales trends, product performance, and potential customer churn.

## Objectives
- Analyze overall sales and revenue.
- Identify high-value customers.
- Analyze potential customer churn.
- Identify top-performing products.
- Compare sales performance across countries.
- Study monthly revenue trends.
- Generate business recommendations.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Data Analysis Performed
1. Data Loading and Understanding
2. Data Cleaning
3. Feature Engineering
4. Sales Performance Analysis
5. Customer Segmentation
6. Monthly Sales Trend Analysis
7. Pivot Table Analysis
8. Customer Churn Analysis
9. Product Performance Analysis
10. Country-wise Sales Analysis
11. Sales Growth Analysis
12. Business Recommendations

## Customer Segmentation
Customers are classified into:
- Low Value
- Medium Value
- High Value

## Customer Churn Analysis
Customers with no purchase for more than 90 days are classified as Potential Churn customers for this analysis.

## Project Files
- Jupyter Notebook (.ipynb)

- Customer Segmentation Report
- Churn Analysis Report
- Product Analysis Report
- Country Analysis Report
- Monthly Sales Report

## Conclusion
This project provides insights into customer behavior, sales performance, and potential churn risks. The analysis helps businesses improve customer retention, identify profitable products, and make data-driven decisions.
